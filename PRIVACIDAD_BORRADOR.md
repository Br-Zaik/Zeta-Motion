# Borrador de política de privacidad (NO publicar sin revisar)

**Zeta Motion** es una aplicación de edición local de imágenes animadas. Esta versión de código no solicita permiso de Internet y no incorpora servicios de anuncios, analítica ni cuentas de usuario.

Las imágenes elegidas, las máscaras, los proyectos y sus ajustes se almacenan en el dispositivo para que puedas continuar editando. Al exportar o compartir, el usuario elige explícitamente a qué destino enviar el archivo. El sistema operativo Android podría ofrecer copias de seguridad o transferencias de datos conforme a la configuración del dispositivo; revisar el comportamiento real en el dispositivo antes de publicar esta declaración.
